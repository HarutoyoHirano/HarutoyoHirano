## About

生体計測・信号処理・機械学習を組み合わせて，臨床の現場にある課題を解く医療機器やシステムをつくっています．
センサの設計から信号解析，予測モデル，臨床で使えるソフトウェアまで，一人で端から端まで手を動かすのが得意です．

I build medical devices and systems that solve real problems in clinical settings, combining biomedical
measurement, signal processing, and machine learning — from sensor hardware to signal analysis,
predictive models, and software clinicians can actually use.

## What I work on

| Theme | 概要 |
|---|---|
| 🫀 **Early detection of arteriosclerosis** | 動脈硬化を早く，手軽に見つける — 血管内皮機能（FMD）の非侵襲評価 |
| 🩸 **Vascular mechanics → sensation** | 血管の硬さ（粘弾性 β）から痛みや緊張を定量化する |
| 🪑 **Cuffless continuous blood pressure** | 着けるだけ，座るだけで血圧と心拍を測る |
| 🔄 **Safer cardiopulmonary bypass** | 人工心肺中のヘモグロビン濃度を機械学習で予測する |
| 🧠 **Post-stroke prediction** | 脳卒中後の回復・合併症（せん妄など）を予測する |
| 📈 **Early warning from bio-signals** | 生体信号から体調の変化をいち早く捉える |
| 🏠 **Home hemodialysis support** | 在宅透析のための自己血管内シャント管理 |

## Toolbox

- **Measurement**: pulse-wave sensors, oscillometric blood pressure, chair-type unconstrained sensing, head-up tilt testing
- **Analysis**: biomedical signal processing, vascular viscoelastic modeling, heart-rate variability
- **ML**: regression / classification for clinical prediction (e.g., SVR), image-based assessment
- **Code**: Python, MATLAB, Google Apps Script — plus web (GitHub Pages for the [lab site](https://hiranolab.github.io/))
- **AI-assisted development**: using Claude to turn clinical ideas into working tools quickly
